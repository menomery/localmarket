# AGENTS.md

## LocalMarket Engineering Rules

1. Build incrementally.
2. Never destroy working code without permission.
3. Inspect before modifying.
4. Use TypeScript.
5. Use Firebase Authentication.
6. Use Cloud Firestore.
7. DO NOT use Firebase Storage.
8. DO NOT use Google Cloud Storage for the current MVP.
9. Use Google Drive for current media storage.
10. Keep Google Drive behind a storage abstraction.
11. Never expose private Google credentials.
12. Never expose secrets.
13. Never trust frontend roles.
14. Protect Firestore data.
15. Protect Google Drive operations.
16. Run typecheck.
17. Run lint.
18. Run build.
19. Do not create fake production integrations.
20. Keep UI mobile-first.
21. Optimize for low-end Android.
22. Do not implement future features unless requested.
23. Do not change unrelated features.
24. Do not overwrite existing working code unnecessarily.
